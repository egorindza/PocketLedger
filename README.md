# PocketLedger

Личный менеджер подписок и расходов. В карточке подписки хранится текущий тариф и дата ближайшего списания. Когда платёж состоялся, укажите фактическую сумму и дату. PocketLedger запишет расход и передвинет дату на следующий цикл.

## Запуск

Требуется .NET 10 SDK.

```powershell
Set-Location C:\Portfolio\PocketLedger
dotnet build
dotnet run
```

Интерфейс доступен на [localhost:5111](http://localhost:5111). Ссылка «Посмотреть пример» на главной показывает демонстрационные данные без записи в личную базу.

## Как пользоваться

1. На обзоре нажмите «Подписка» и добавьте цену, валюту, период и ближайшую дату.
2. После списания нажмите «Записать» рядом с подпиской. Если списания не было, перенесите дату или поставьте подписку на паузу.
3. Нажмите «Расход», чтобы записать покупку, не привязанную к подписке.
4. В истории выберите месяц, год или весь период. Список можно отфильтровать по валюте и экспортировать в CSV.

Изменения тарифа видны в карточке подписки. Правки фактического расхода также сохраняются. Рубли, доллары и евро суммируются отдельно. Карточка предстоящих платежей показывает по одному ближайшему списанию каждой подписки, которое попадает в 30-дневное окно, включая просроченное.

## Устройство

ASP.NET Core MVC с серверным Razor и CSS, один проект и один файл SQLite. Суммы хранятся в копейках или центах. Запись платежа и перенос даты выполняются одной транзакцией, а уникальный ключ защищает от двойной записи одного цикла.

Личные записи в `App_Data/pocketledger.db`. Чтобы сделать копию, остановите приложение и скопируйте каталог `App_Data`. Менеджер слушает loopback, вход в аккаунт для локального использования не нужен. Порт настраивается через `PocketLedger__Port`, путь к базе — через `PocketLedger__DataPath`. Приложение рассчитано на одно устройство.
